# Ambiance sonore personnalisée

Dépose ici un fichier `ambiance.mp3` : le bouton d'ambiance du header le jouera en boucle
à la place de l'ambiance générée. Utilise uniquement un son dont tu as les droits
(la politique « Legal Jibber Jabber » de Riot encadre l'usage de ses assets dans les projets de fans).
