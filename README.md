# Binderbound

**Binderbound** is a web app that helps Riftbound TCG collectors organize their physical binders.

Choose a set, pick your binder format (2x2, 3x3, 4x3 or custom), set your sorting preferences, and Binderbound tells you exactly where each card goes: sheet, front or back, row and column. Alternate arts, overnumbered, signature and promo variants are all taken into account.

## Features
- Binder layouts: 2x2, 3x3, 4x3 or custom grid, single or double-sided
- Sorting by collector number, domain, rarity or type
- Variants placed after their base card, grouped at the end, or excluded
- Optional page breaks per domain, reserved pages, right-side start
- Visual binder view, list view and card search
- Collection tracking: missing cards keep their slot
- CSV export and print-friendly layout
- Available in French and English

## Tech stack
Node.js · Express · React · Vite · react-i18next · Vitest
